# Frontendacademia

> Frontend da aplicacao de academia (gym) desenvolvido com Next.js, React e integracao com API AdonisJS para gestao de alunos e planos.

## Stack

- Next.js
- Axios

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/frontendacademia.git
cd frontendacademia

# Instale as dependencias
npm install

# Inicie a aplicacao
npm run dev
```
